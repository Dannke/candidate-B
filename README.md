# Отчёт по расчётам с подрядчиками

По файлам из папки `data/` строит отчёт на любую дату: по каждой работе — цена, выплачено, осталось;
по каждому договору — итоги, сумма договора, переплата и платежи в очереди.

## Что нужно

Python 3.10 или новее. Ничего устанавливать не надо — только стандартная библиотека.

## Как запустить

Из папки проекта:

```bash
python report.py --date 2026-11-10
```

Дата — в виде `ГГГГ-ММ-ДД`, учитывается включительно. Если в файлах ошибка, отчёт не строится,
а программа пишет, в каком файле и какой строке что не так.

Тесты:

```bash
python -m unittest -v
```

## Файлы

- `report.py` — программа. Правило зачёта платежей — функция `distribute`, меняется только она.
- `test_report.py` — тесты: контрольные цифры на 24.08, 05.09, 10.11, 12.11, сверка сумм на каждую дату, ошибки в данных.
- `DECISIONS.md` — все допущения: что выбрано и что изменится в отчёте, если выбор неверен.
- `NOTE.md` — записка бухгалтеру: что нужно подтвердить.
- `data/` — выгрузка из учёта, программа её только читает.
